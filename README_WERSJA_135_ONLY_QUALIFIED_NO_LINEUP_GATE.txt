Zmiany:
1. Skład XI NIE jest już warunkiem dopuszczenia meczu do symulacji.
2. Wymagane są tylko kluczowe realne dane sportowe:
   - minimum 5 ostatnich realnych meczów gospodarzy,
   - minimum 5 ostatnich realnych meczów gości,
   - statystyki obu drużyn wyliczone z realnych ostatnich spotkań / danych sezonowych.
3. Kursy 1X2, H2H, tabela, absencje, prognoza API i XI są dodatkami — nie blokują meczu.
4. Lista "Mecze dnia" wykonuje lekki pre-check każdego przyszłego meczu i pokazuje tylko zakwalifikowane spotkania.
5. Odrzucone mecze nie są wyświetlane użytkownikowi.
6. Lista jest budowana progresywnie w paczkach po 6 meczów i zachowuje sortowanie od najbliższego kickoffu.
7. Pre-check używa tylko realnych ostatnich meczów obu drużyn, dzięki czemu nie odpala ciężkiego pełnego Match Engine dla każdego spotkania.
