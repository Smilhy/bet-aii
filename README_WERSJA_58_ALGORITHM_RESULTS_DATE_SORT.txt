BetAI WERSJA 58 — Algorytm / Wyniki — sortowanie po dacie

Baza: WERSJA 57 Mobile Fast Start Session Performance.

Zmiana:
- Zakładka Algorytm → Wyniki domyślnie pokazuje mecze od NAJNOWSZEGO do NAJSTARSZEGO.
- Dodano przycisk z kierunkiem ↓ / ↑.
- ↓ Najnowsze → najstarsze (domyślnie).
- ↑ Najstarsze → najnowsze.
- Pozostałe zakładki Algorytmu zachowują dotychczasowe sortowanie od najbliższego startu do najpóźniejszego.
- Nie zmieniono modelu, prawdopodobieństw, kursów, stawek, rozliczeń ani Supabase.
- Nie potrzeba SQL.
