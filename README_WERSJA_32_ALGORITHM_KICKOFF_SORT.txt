WERSJA 32 — ALGORYTM: MECZE POSORTOWANE GODZINAMI

Baza: Wersja 31.

Zmieniono tylko dolną listę meczów w zakładce „Algorytm”:
- mecze są wyświetlane chronologicznie,
- od najwcześniejszej daty i godziny rozpoczęcia,
- następnie coraz późniejsze mecze,
- rekordy bez poprawnej godziny trafiają na koniec.

Przykład kolejności:
14:00 → 14:20 → 16:30 → 18:15 → 20:00.

Nie zmieniono:
- logiki algorytmu,
- wyboru typów,
- prawdopodobieństw,
- kursów,
- stawek,
- skanowania,
- rozliczania,
- Supabase ani SQL,
- wyglądu pozostałych sekcji.
