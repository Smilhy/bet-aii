NOWOŚCI V376
=============
1. VERIFIED RECORD
- historia do 250 ostatnich wpisów forward trackera z zamrożonym typem,
- wyszukiwarka po drużynie / lidze / rynku / fixture ID,
- filtry ALL / WIN / LOSS / PENDING / VOID,
- wskaźnik integralności pre-match,
- licznik rekordów zapisanych przed kickoffem,
- licznik rekordów wymagających sprawdzenia.

2. PREDICTION PASSPORT
Kliknięcie dowolnego wpisu otwiera paszport typu:
- mecz i liga,
- rynek i zamrożony kurs,
- AI probability,
- fair odds,
- implied market price (1/odds),
- edge i EV,
- reliability i daily score,
- czas pierwszej publikacji,
- kickoff,
- wynik / status / profit,
- model version,
- settlement source,
- record ID i fixture ID.

3. VERIFIED TIMELINE
Paszport pokazuje chronologicznie:
PUBLISHED -> KICK-OFF -> SETTLEMENT
oraz oznacza czy pierwszy zapis typu był rzeczywiście przed kickoffem.

4. KLIKALNE WPISY
Paszport można otworzyć z:
- Verified Record,
- Ostatnich typów systemu,
- listy typów po kliknięciu konkretnej ligi.
